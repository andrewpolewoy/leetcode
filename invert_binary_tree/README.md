#226. Invert Binary Tree
<br><b>Easy</b>

Given the root of a binary tree, invert the tree, and return its root.<br>
![img.png](img.png)<br>

<b>Example 1:<br>
![img_1.png](img_1.png)<br>
Input: root = [4,2,7,1,3,6,9]<br>
root2 = [3,5,1,6,7,4,2,null,null,null,null,null,null,9,8]<br>
Output: [4,7,2,9,6,3,1] <br>

Example 2:<br>
![img_2.png](img_2.png)
Input: root = [2,1,3]<br>
Output: [2,3,1] <br>

Example 3:<br>
Input: root = []<br>
Output: []<br>

Constraints:<br>
The number of nodes in the tree is in the range [0, 100].<br>
-100 <= Node.val <= 100<br>
